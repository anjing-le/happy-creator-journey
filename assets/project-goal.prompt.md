# 项目目标与意义配图

生成方式：内置 ImageGen。

## 生成提示词

Use case: illustration-story
生成一张横向3:2的无文字蜡笔手绘插画，用于表达“从真实成长与作品出发，逐步积累自己的创作最佳实践，并将作品与经验分享给更多人”。
输入参考图仅作为纸张质感、蜡笔笔触、抽象人物造型和留白尺度的参考，不复制其中的标题、文字、机器人、种树情节、网页边框或红线。
画面只画一个温暖朴拙的完整场景：一位穿鼠尾草绿衣服的性别中性极简小人坐在地上，在打开的创作笔记上画一株幼苗，身旁整齐叠着两本积累的笔记；小人微笑着将一张画有成长小树的完成作品递给另一位浅蓝衣服的极简小人，接收者身旁再有一位小读者凑过来欣赏。用“创作笔记—积累的本子—分享画作”的自然动作表达成长、积累、分享，全部融入一个紧凑的主体场景，不画流程图、不画箭头、不画分栏。
主体集中在画面中央，占画面大约一半至六成宽度，上下左右留舒展自然的米白纸面。人物为圆润抽象小人，点状眼睛、轻微微笑、少量淡腮红，不用具体IP，不画写实面部，不画复杂头发。
整体完全采用温暖的米白纸张底色，细腻自然纸纤维贯穿至边缘。粗黑色略抖动的手绘轮廓，真实蜡笔涂色的颗粒、笔触与空隙。以柔和浅蓝、奶油黄、鼠尾草绿为主，低饱和、少量用色，画面简洁可爱但不过度装饰。
严格零文字：没有标题、没有副标题、没有说明、没有标签、没有数字、没有字母、没有汉字、没有伪文字，书本和画作上仅有简单植物图画。不要刻意给标题或正文预留版式区域。
无纯白边框、无投影、无暗角、无水印，无写实照片、动漫、3D、光滑矢量、霓虹科技风、金属感、复杂背景。
