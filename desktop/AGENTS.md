# CreatorX 客户端协作约束

- **Creation Harness 定位**：CreatorX 不是重新造一个通用 Agent，而是构建在本地 Agent 之上的创作约束与编排客户端。通过 `library`（IP 底座＋样板间）、`harness`（只读快照锁、结构化蓝图门禁、槽位产物硬校验与版本链、样板反哺）与 `adapters`（可插拔本地 Agent 适配器）三层解耦实现。详见 [ARCHITECTURE.md](ARCHITECTURE.md)。
- **首页布局与视觉**：首页上方约七成为**“图文、视频”**两张安静 IP 无字蜡笔插画入口，下方约三成为横跨整行的**“样板间”**无字插画入口，整体铺满窗口，仅留细窄分隔。卡片尺寸固定，悬停仅做轻微位移缩放与透明度反馈，尊重减少动态效果设置；首页不显示可见文字或原生提示，保留无障碍读屏名称与聚焦轮廓。
- **三大交付制式**：“图文”入口内置切换 **`卡片图文`**（小红书／抖音多图卡片＋短配文）与 **`长文配图`**（微信公众号 Markdown 长文＋封面／插图）；“视频”入口对应 **`视频创作`**（口播逐字稿＋分镜镜头卡＋关键帧／提示词包）。
- **四道硬门禁**：① 任务启动或更换挂载时冻结 `snapshots/<seq>/` 只读快照（默认可带入 IP 底座）；② 形成结构化 `blueprint.json`／`draft.md` 并经确认放行后才开放槽位渲染；③ 槽位产物写入 `artifacts/<slot-id>/v<N>.<ext>`，核验真实图像文件头且严格追加版本、禁止覆盖旧版；④ 支持将成品提炼回写样板间。
- **可插拔本地 Agent**：首期落地 `CodexAdapter`（连接本机已登录 `codex app-server`，固定 `gpt-6.1-sol`／`medium`），预留 `AntigravityAdapter` 标准接口；客户端不复制托管第三方凭据。
- **资产与样板间**：包含唯一 **IP 底座**（`ip.json`）、**制式 Skills**（真实文件夹）与 **风格提示词**，支持按赛道与成熟度（`样板`／`草稿`）筛选，画廊以真实样例为第一视觉。界面与本地 CLI 共用存储、跨进程文件锁和 `revision` 乐观并发检查。私人数据与历史归档绝不入库或进入公开安装包。
- **桌面体验**：暖米白柔和配色，所有选择器统一使用自定义 `Choice` 米白弹层，禁用原生 `select`／`datalist`。macOS 隐藏左上角三按钮，`Command + W` 隐藏窗口保活、`Command + Q` 完全退出；Windows 保留原生窗口按钮。全局支持 `Command + [`／`]` 与鼠标侧键 `button 3/4` 前进后退，存在未保存编辑（`[data-editing]`）或打开弹层时保护页面。
- **更新与图标边界**：OTA 每小时静默检查，仅确认有新版时显示按钮，存在编辑或运行中创作任务时阻止安装；使用独立更新签名密钥。macOS 本机退出图标采用 `scripts/macos-file-icon.swift` 设置 Finder 自定义图标，**仅限本机安装后定制**，不得写入 CI 安装包或公证产物。
- **仓库首页约束**：根目录 `README.md` 保持经认可的图片展示，开发与架构说明放在本目录与根目录 `design.md`。
