# CreatorX

- 首页为上排“文、图片、视频”三张安静 IP 插画，下排横跨整行的“素材库”插画色块。首页不显示任何可见文字（含悬停文案与标题提示），仅保留无障碍名称和聚焦轮廓；整块可点击。文、图、视频分别打开 Codex 对话框，各自保存历史，不合并入口或共享当前对话。
- 创作通过本机 Codex app-server，固定 gpt-6.1-sol / medium；使用现有登录。先与 Codex 自然交流，Skill 和提示词是可选附件，允许在聊天中更换；方法与 SOP 随实践打磨，不把两步图文流程写死在界面里。原生生图与改图保留旧版。Skill、参考图和提示词按任务快照保存，不自动发布；后台任务未完成时阻止 OTA 安装。
- 素材库先只有提示词和 Skills 两种。提示词以正文为核心，支持自行维护分类、搜索、备注、参考图、来源和复制；不自动生成用途标签，不提供用途筛选；Skill 以真实文件夹维护，根目录 SKILL.md，保留脚本及资源。导入不等于执行。
- 界面与 CLI 共用存储、进程间文件锁和修订检查；更新必须基于当前修订，外部 SKILL.md 修改也不能静默覆盖。私人素材与迁移导出不嵌入公共安装包或提交到 GitHub；来源原文不自动改写。
- 面向 macOS 与 Windows，使用统一暖米白背景、低饱和淡色块与留白中的透明蜡笔插画，保持干净素净；延续原生窗口操作。保留文字编辑与缩放光标的系统语义。
- 不分发参考客户端仅供个人使用的第三方光标；本仓库光标为独立原创资产。
- OTA 沿用 macos-x 的安静检查、提示新版、用户确认后下载验签并安装的习惯；跨平台实现使用 Tauri updater。无可用更新与网络失败分别处理。
- CreatorX 使用独立更新签名密钥，私钥不得入库；发布须验证全部平台签名及版本一致性。更新签名不等于平台代码签名或公证。
- 根目录 README 保持图片展示，具体开发和发布说明放在本目录。
