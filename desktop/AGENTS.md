# CreatorX

- 首页为上排“文、图、视频”三个入口，下排“素材库”。本轮先打磨素材库，三个创作工作区暂不接入生成能力。
- 素材库由各创作入口共用，默认是当前用户的本地资料，不自动公开。角色以样图展示、背后维护提示词；场景以套图展示、背后维护 Skill 文档。规则默认折叠，不能把场景简化为一条生图提示词。
- 用户的角色、样图和 Skill 保存在应用数据目录，不嵌入公共安装包；样图不等于完整 Skill，保存 Skill 文档不代表已经能执行。原始乐谱等保真资料不通过生图擅自改写。
- 面向 macOS 与 Windows，沿用 EnglishX／FinanceX 的深灰、暖灰、克制金色和原生窗口操作。保留文字编辑与缩放光标的系统语义。
- 不分发参考客户端仅供个人使用的第三方光标；本仓库光标为独立原创资产。
- OTA 沿用 macos-x 的安静检查、提示新版、用户确认后下载验签并安装的习惯；跨平台实现使用 Tauri updater。无可用更新与网络失败分别处理。
- CreatorX 使用独立更新签名密钥，私钥不得入库；发布须验证全部平台签名及版本一致性。更新签名不等于平台代码签名或公证。
- 根目录 README 保持图片展示，具体开发和发布说明放在本目录。
