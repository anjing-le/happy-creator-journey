# CreatorX

- 首页上方约七成为“文、图片、视频”三张安静 IP 插画色块，下方约三成为横跨整行的素材库插画区域，整体铺满窗口，仅保留细窄分隔。卡片尺寸固定；悬停只做短促、轻微的插画位移缩放与透明度反馈，不做宽度动画、果冻形变或弹性回弹，尊重减少动态效果设置。首页不显示任何可见文字（含悬停文案与标题提示），仅保留无障碍名称和聚焦轮廓；整块可点击。文、图、视频分别打开 Codex 对话框，各自保存历史，不合并入口或共享当前对话。
- 创作通过本机 Codex app-server，固定 gpt-6.1-sol / medium；使用现有登录。先与 Codex 自然交流，Skill 和提示词是可选附件，允许在聊天中更换；方法与 SOP 随实践打磨，不把两步图文流程写死在界面里。图工作区采用左侧主会话、右侧生图任务与作品。新建图会话通过受控动态工具派发独立 Codex 生图子会话，继承本轮素材快照，回传实际图片；修改引用原任务图片并保留旧版。内置单张图文、系列图文和图片修改 Skill，放在输入框下方选择，不写入私人库。旧会话保留直接执行方式与历史。Skill、参考图和提示词按任务快照保存，不自动发布；后台任务未完成时阻止 OTA 安装。
- 素材库先只有提示词和 Skills 两种。提示词以正文为核心，支持自行维护分类、搜索、备注、参考图、来源和复制；不自动生成用途标签，不提供用途筛选；Skill 以真实文件夹维护，根目录 SKILL.md，保留脚本及资源。导入不等于执行。
- 界面与 CLI 共用存储、进程间文件锁和修订检查；更新必须基于当前修订，外部 SKILL.md 修改也不能静默覆盖。私人素材与迁移导出不嵌入公共安装包或提交到 GitHub；来源原文不自动改写。
- 面向 macOS 与 Windows，使用统一暖米白背景、低饱和淡色块与留白中的透明蜡笔插画，保持干净素净；延续原生窗口操作。保留文字编辑与缩放光标的系统语义。macOS 隐藏原生关闭、最小化、全屏按钮，保留顶部拖动与窗口缩放；Command + W 暂时隐藏窗口，重新打开恢复原窗口与状态，Command + Q 才退出。Windows 保留原生窗口按钮。
- 应用内选择器统一使用 Choice 自定义组件，不使用系统原生 select、datalist 或原生标题提示。对话切换、Skill、分类候选共用米白弹层、选中态、悬停反馈、键盘导航和关闭规则；弹层自动避让窗口边缘。保留系统窗口快捷键、文本编辑和文件访问能力。
- 页面历史共用单一导航状态：Command + [ 后退、Command + ] 前进；鼠标侧键 button 3 后退、button 4 前进，Alt + 左右键兼容。空白输入框聚焦不阻挡导航；未发送内容、素材编辑或打开弹层时保护当前页面。侧键仅在 mouseup 导航一次，拦截 WebView 默认历史；连续导航和历史分支不得使用旧状态。
- 不分发参考客户端仅供个人使用的第三方光标；本仓库光标为独立原创资产。
- OTA 启动后按约一小时周期安静检查，唤醒或切回窗口时补查到期任务；首页更新按钮仅在确认有可用新版时显示，检查中、无新版或后台网络失败时均不显示。用户确认后才下载验签并安装；跨平台实现使用 Tauri updater。无可用更新与网络失败分别处理。
- CreatorX 使用独立更新签名密钥，私钥不得入库；发布须验证全部平台签名及版本一致性。更新签名不等于平台代码签名或公证。
- 根目录 README 保持图片展示，具体开发和发布说明放在本目录。
