# 卡片图文样板（小红书／抖音多图卡片）

1. **立意与事实对齐**：先结合创作者的 IP 底座、赛道定位与真实素材，明确本篇卡片要解决受众的哪一个具体问题，不编造经历或数据。
2. **产出分页蓝图契约（渲染前必经门禁）**：在未获确认前禁止直接生成图片。先整理发布标题、短配文，以及 3～7 页卡片蓝图（写入 `blueprint.json` 或调用 `creatorx_update_blueprint`）：
   - 第 1 页为封面卡（直白主标题＋视觉锚点）；
   - 后续每页只讲清一个要点，明确写入图内的**逐字准确文案**与构图说明，控制单页字数留白。
3. **按槽位生成与核验**：蓝图放行后，按 `slotId` 派发独立生图任务；第 1 页确立纸面、字形与角色一致性，后续页沿用同一视觉基准。
4. **单页微调保留旧版**：哪一页需要调整，只针对对应 `slotId` 引用上一版真实原图生成新版本，严禁重画无关页面或覆盖旧图。
