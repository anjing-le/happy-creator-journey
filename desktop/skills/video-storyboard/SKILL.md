# 视频分镜样板（抖音／小红书视频）

1. **钩子与核心交付**：明确前 3 秒开场问题／反直觉结论，确保整条视频只讲透一件事，口语自然紧凑、贴合创作者 IP 口吻。
2. **口播定稿与分镜蓝图（渲染前必经门禁）**：将完整口播／旁白逐字稿写入 `draft.md`，并在 `blueprint.json` 拆解结构化镜头表（每个 `slotId` 对应一镜：镜号标题、对应台词、画面主体与运镜动作、预计秒数）。
3. **关键帧与视频提示词产出**：蓝图放行后，可按镜头槽位生成关键帧视觉参考图，或整理结构化镜头提示词供视频渲染／生成环节使用；不把文字脚本冒充已生成的视频文件。
4. **单镜修订**：调整某一镜台词、时长或参考画面时，只更新对应镜头槽位并保留历版参考帧。
