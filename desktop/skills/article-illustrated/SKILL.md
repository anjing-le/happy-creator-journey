# 长文配图样板（微信公众号／深度图文）

1. **结构与立意打磨**：结合创作者 IP 口吻与真实技术／行业实践，先拉清文章主线结论与小节脉络，拒绝空话套话与焦虑式标题。
2. **定稿正文与插图锚点蓝图（渲染前必经门禁）**：将定稿 Markdown 正文写入 `draft.md`（正文内可用 `![封面](slot:cover)`、`![配图1](slot:fig-1)` 标记插图位置），并在 `blueprint.json` 列出封面图与文中关键概念插图的构图及图内说明文字。未经确认前不提前生图。
3. **生成封面与概念插图**：蓝图确认放行后，按封面与插图槽位逐一派发生图任务，延续选定画风与 IP 设定，辅助读者理解抽象结构或对比关系。
4. **单图返修与成稿核对**：配图需调整时仅针对目标槽位引用原图迭代新版本，保持正文与其余配图稳定。
